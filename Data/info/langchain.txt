LangChain is an open-source framework used to build applications powered by Large Language Models.
Large Language Models can understand and generate human-like text based on user prompts.
Retrieval Augmented Generation (RAG) combines document retrieval with LLM-based response generation.
Vector databases store numerical representations of text called embeddings.
Embeddings help identify semantically similar content even when exact keywords do not match.
Prompt engineering involves designing effective instructions to guide LLM responses.
LangGraph is a framework used to build stateful and multi-step AI agent workflows.
Agents can use external tools to perform tasks based on user instructions.
Temperature controls the randomness of responses generated by language models.
Hallucination occurs when an LLM generates incorrect or unsupported information.
